# Security

This repository is a testing checklist for people who already have authorization.

- Do not open issues that name a commercial product, a private bug, or a non-public interface.
- Vendor-specific vulnerabilities belong in that vendor's private tracker, not here.
- The only code in this repo is a native-API file-copy sample. It is not a vulnerability report.

If you believe [nt-copyfile.cpp](examples/U-01/nt-copyfile.cpp) itself is harmful in a context we missed, open an issue that describes the concern without a payload.
