# G-07

Test driver-start config integrity.

1. Identify the config file or registry blob the driver reads during DriverEntry.
2. Back up the original.
3. Replace with a crafted config (e.g., disable all protections, set empty allowlist).
4. Reboot.
5. If the driver validates the config (cryptographic signature) and rejects the replacement, record `hold`.
6. If the driver loads the crafted config, record `miss`.
7. Restore the config. Revert from snapshot.
