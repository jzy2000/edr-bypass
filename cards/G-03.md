# G-03

Test whether WDAC can be weaponized against the product.

1. Create a WDAC deny policy for the product:
   ```powershell
   New-CIPolicy -Level FileName -Deny -FilePath "%install_dir%\<agent_exe>" -UserPEs -PolicyPath C:\TEMP\deny.xml
   ```
2. Convert: `ConvertFrom-CIPolicy C:\TEMP\deny.xml C:\TEMP\deny.bin`.
3. Deploy: copy to `C:\Windows\System32\CodeIntegrity\SIPolicy.p7b` and reboot.
4. After reboot, check if the product can start.
5. If the product is blocked by WDAC, record `miss` — an admin can weaponize OS policy against the product.
6. If the product resists (ELAM, PPL, or is in the WDAC trust chain), record `hold`.
7. Remove the policy. Revert.
