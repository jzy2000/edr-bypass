# N-02

Test whether WFP-level network filtering blocks the product.

1. Open the WFP engine: `FwpmEngineOpen(NULL, RPC_C_AUTHN_DEFAULT, NULL, NULL, &engine)`.
2. Add a sublayer and a blocking filter at a high weight targeting the product's destination IPs/ports.
3. Verify the product cannot reach the cloud: check the product log for connectivity errors.
4. Run the S-03 baseline. If local detection continues, record `hold` for local enforcement.
5. If the product also detects the WFP rule addition and alerts, record `hold` with extra credit.
6. If the product silently loses connectivity and local detection degrades, record `miss`.
7. Remove the WFP filter: `FwpmFilterDeleteById`.
