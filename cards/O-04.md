# O-04

Test remote and scheduled execution detection.

1. Create a known-detected payload.
2. Execute via:
   a. `schtasks /create /tn EDR_TEST /tr "C:\TEMP\payload.exe" /sc once /st 00:00 /ru SYSTEM & schtasks /run /tn EDR_TEST`
   b. `wmic process call create "C:\TEMP\payload.exe"`
   c. `winrs -r:localhost C:\TEMP\payload.exe`
   d. PowerShell: `Invoke-WmiMethod -Class Win32_Process -Name Create -ArgumentList "C:\TEMP\payload.exe"`
3. Check the product log after each.
4. If all are detected, record `hold`. If any evade, record `miss`.
5. `schtasks /delete /tn EDR_TEST /f`.
