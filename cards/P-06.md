# P-06

Test whether the product logs the real parent or the spoofed one.

## Part 1: PPID Spoofing

1. Open a process to use as the fake parent (e.g., `explorer.exe`): `OpenProcess(PROCESS_CREATE_PROCESS, FALSE, explorerPid)`.
2. Set up the attribute list:
   ```c
   InitializeProcThreadAttributeList(attrs, 1, 0, &size);
   UpdateProcThreadAttribute(attrs, 0, PROC_THREAD_ATTRIBUTE_PARENT_PROCESS,
                             &hFakeParent, sizeof(HANDLE), NULL, NULL);
   ```
3. `CreateProcessW("C:\\Windows\\System32\\notepad.exe", ..., EXTENDED_STARTUPINFO_PRESENT, ...)` with the attribute list.
4. Read the product log. If it shows `explorer.exe` as the parent, record `miss`. If it shows the real parent or flags the spoof, record `hold`.

## Part 2: Command Line Spoofing

1. Create a process suspended with a long command line: `CreateProcessW(NULL, "notepad.exe                    ", ..., CREATE_SUSPENDED, ...)`.
2. Read PEB: `NtQueryInformationProcess(ProcessBasicInformation)` → PEB → `ProcessParameters` → `CommandLine`.
3. Overwrite the command line in the PEB with `WriteProcessMemory`: replace with `"svchost.exe -k netsvcs"`.
4. Resume the process.
5. Read the product log. If it shows the overwritten command line, record `miss`. If it captures the original, record `hold`.

6. Terminate both test processes.
