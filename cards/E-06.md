# E-06

Test Authenticode parser robustness.

1. Sign a test binary normally.
2. Corrupt the Authenticode:
   a. Truncate the PKCS#7 blob mid-DER.
   b. Replace the certificate chain with garbage.
   c. Set the certificate directory size to UINT_MAX.
   d. Add a self-referencing ASN.1 SEQUENCE.
3. Trigger a scan on each corrupted binary.
4. If the product rejects them and stays up, record `hold`.
5. If the product crashes or accepts one as valid, record `miss`.
Delete test binaries.
