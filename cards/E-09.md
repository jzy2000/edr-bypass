# E-09

Test ETW/Event Log consumer robustness.

1. Register a custom ETW provider: `EventRegister`.
2. Write events with:
   a. Extremely long strings (1 MB payload).
   b. Malformed XML in the event data.
   c. Null bytes in string fields.
   d. Thousands of rapid events (flood).
3. Check if the product's event consumer crashes, hangs, or stops processing.
4. If it handles all gracefully, record `hold`. If any cause a failure, record `miss`.
