# L-03

Test the depth of the driver's Authenticode validation.

1. Create a self-signed certificate with the same subject name as the product: `New-SelfSignedCertificate -Subject "CN=<product_company>" -CertStoreLocation Cert:\CurrentUser\My`.
2. Sign a test binary with it: `signtool sign /fd SHA256 /a /s My /n "<product_company>" test.exe`.
3. Place the signed binary where the driver would verify it (e.g., the companion DLL path, or present it as the update binary).
4. Trigger the verification (start the service, or trigger the code path that checks signatures).
5. If the driver rejects it (chain does not root in a trusted CA), record `hold`.
6. If the driver accepts it (subject string match only), record `miss`.
7. Delete the test certificate: `Get-ChildItem Cert:\CurrentUser\My | Where Subject -match "<product_company>" | Remove-Item`.
