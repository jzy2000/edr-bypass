# A-09

Gate: SEH scope.

For every crash finding:
1. Is the fault caught by a structured exception handler (SEH)?
2. If yes, where is the SEH frame? In the outer function, or in a deferred work item / DPC / callback?
3. A fault caught by SEH in the same function is not exploitable for code execution.
4. A fault in a DPC or work item may BSOD even with an SEH in the caller.
5. Document the SEH scope for each crash.
