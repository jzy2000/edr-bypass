# O-01

Test whether the product detects common LOLBAS techniques.

1. **certutil decode**: Base64-encode a benign test file. `certutil -encode test.exe test.b64`. Then decode: `certutil -decode test.b64 test_decoded.exe`. Check the log.
2. **certutil download**: `certutil -urlcache -split -f http://<your-server>/test.txt C:\TEMP\test_downloaded.txt`. Check the log.
3. **bitsadmin download**: `bitsadmin /transfer testjob /download /priority normal http://<your-server>/test.txt C:\TEMP\bits_test.txt`. Check the log.
4. **mshta execution**: `mshta "javascript:var s=new ActiveXObject('WScript.Shell');s.Run('calc.exe');close();"`. Check the log.
5. **rundll32 proxy**: `rundll32 javascript:"\..\mshtml,RunHTMLApplication";document.write("test")`. Check the log.
6. For each technique, if the product alerted, note `hold`. If it completed silently, note `miss`.
7. Record a composite result: `hold` if all were detected, `miss` if any evaded, noting which ones.
8. Delete all test files.

Reference: [LOLBAS Project](https://lolbas-project.github.io/).
