# D-05

Test whether AppInit_DLLs / AppCertDlls are monitored.

1. Check current state: `reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows" /v AppInit_DLLs`.
2. Check `LoadAppInit_DLLs` (must be 1) and `RequireSignedAppInit_DLLs` (if 1, unsigned DLLs won't load — record `inconclusive` for unsigned test).
3. Build a test DLL (writes marker in DllMain).
4. Set: `reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows" /v AppInit_DLLs /d "C:\TEMP\test_appinit.dll" /f`.
5. Set: `reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows" /v LoadAppInit_DLLs /t REG_DWORD /d 1 /f`.
6. Start a new GUI process: `notepad.exe` (loads user32.dll, which triggers AppInit_DLLs).
7. Check for the marker file. If present, the DLL was loaded — record `miss` if the product didn't detect it.
8. Also test `AppCertDlls`: `reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\AppCertDlls" /v TestDll /d "C:\TEMP\test_appcert.dll" /f`.
9. Trigger: `CreateProcessW("notepad.exe")`. Check marker.
10. Cleanup: clear the registry values. Delete the DLLs. Close notepad.
