# R-03

Test whether hive-level operations bypass the registry callback.

1. Enable privileges: `SeBackupPrivilege`, `SeRestorePrivilege` (admin has them, just need to enable).
2. Save a protected hive: `RegSaveKeyW(HKEY_LOCAL_MACHINE\SOFTWARE\<product>, "C:\\TEMP\\product_hive.dat", NULL)`.
3. Edit the saved hive offline (add/modify values in the .dat file using a hex editor or offline hive tool).
4. Restore: `RegRestoreKey(hKey, "C:\\TEMP\\product_hive.dat", REG_FORCE_RESTORE)`.
5. If the restore succeeds and the product's values are overwritten, record `miss`.
6. If the callback blocks the restore, record `hold`.
7. Also try: `NtLoadKey` to load the hive under a different path, modify it, then `NtUnLoadKey` and `NtLoadKey` back.
8. Restore from backup.
