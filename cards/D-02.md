# D-02

Test phantom DLL hijacking against the product.

1. On a separate test machine (or with ProcMon from Sysinternals), monitor the product process during startup. Filter for `CreateFile` results of `NAME NOT FOUND` on `.dll` paths. Common candidates: `version.dll`, `winhttp.dll`, `dbghelp.dll`, `wer.dll`, `TextShaping.dll`, `d3d9.dll`.
2. For each candidate, build a test DLL that writes a marker file: `DllMain → CreateFile("%TEMP%\\phantom_<name>.txt") → WriteFile → CloseHandle`.
3. Place the DLL in the same directory as the product binary that searched for it.
4. Restart the service or trigger the code path.
5. Check for marker files. If one exists, the DLL was loaded — record `miss` and name the DLL.
6. If no DLL was loaded (all marker files absent), record `hold`.
7. Delete the planted DLLs and marker files. Restart the service.
