# P-07

Test whether the product detects remote thread injection.

1. Start a target: `notepad.exe`.
2. Open it: `OpenProcess(PROCESS_ALL_ACCESS, FALSE, notepadPid)`.
3. Allocate memory: `VirtualAllocEx(hProc, NULL, 4096, MEM_COMMIT|MEM_RESERVE, PAGE_EXECUTE_READWRITE)`.
4. Write shellcode (a benign marker: write a file to `%TEMP%\injection_proof.txt` then `ExitThread`): `WriteProcessMemory`.
5. Create remote thread: `NtCreateThreadEx(&hThread, THREAD_ALL_ACCESS, NULL, hProc, allocAddr, NULL, FALSE, 0, 0, 0, NULL)` or `CreateRemoteThread`.
6. Wait for the thread to complete: `WaitForSingleObject(hThread, 5000)`.
7. Check for the marker file and read the product log.
8. If the product detected the injection (thread creation from a foreign process), record `hold`.
9. If the marker file exists and the product saw nothing, record `miss`.
10. Terminate notepad.
