# G-01

Test the freeze/coma attack against the agent.

1. Enumerate agent threads: `CreateToolhelp32Snapshot(TH32CS_SNAPTHREAD)`.
2. For each thread: `OpenThread(THREAD_SUSPEND_RESUME, FALSE, tid)` → `SuspendThread(hThread)`.
3. After suspending all threads, the process is alive (sc query shows RUNNING) but not scanning.
4. Wait 60 seconds. Perform the S-03 baseline (write a test file).
5. If a kernel-mode watchdog detects the freeze (alerts, restarts the agent), record `hold`.
6. If the agent stays frozen and detection stops, record `miss`.
7. Resume all threads: `ResumeThread(hThread)` for each.

Also test the WER variant: trigger a fault in the agent that WER handles, keeping the process in a dump state.
