# E-02

Test header vs body content detection.

1. Write a PE file normally (baseline — should be detected).
2. **Header-only**: write just the PE header (first 4096 bytes), pad the rest with zeros. Does the product alert?
3. **Body-only**: write the PE starting at offset 4096 (no header). Does the product alert?
4. **Residual**: write the PE, overwrite it with zeros, then write the PE again. Does the scanner see the first version, the zeros, or the second version?
5. Record which variants are detected. If all are detected, record `hold`. If any evade, record `miss`.
