# H-06

Test whether ObRegisterCallbacks protects thread handles in addition to process handles.

1. Enumerate threads of the agent: `CreateToolhelp32Snapshot(TH32CS_SNAPTHREAD)`, filter by `th32OwnerProcessID == agentPid`.
2. For the first thread, call `OpenThread(THREAD_ALL_ACCESS, FALSE, threadId)`.
3. Inspect `GrantedAccess` via `NtQueryObject(ObjectBasicInformation)`.
4. Check key rights:

| Right | Value | Stripped? |
|---|---|---|
| THREAD_SUSPEND_RESUME | 0x0002 | should be |
| THREAD_SET_CONTEXT | 0x0010 | should be |
| THREAD_IMPERSONATE | 0x0100 | should be |
| THREAD_TERMINATE | 0x0001 | should be |
| THREAD_GET_CONTEXT | 0x0008 | check |

5. If invasive rights are stripped, record `hold`. If any are present, record `miss`.
6. If `THREAD_SUSPEND_RESUME` is present, try `SuspendThread`. If all threads are suspended for 60 seconds and the product stops enforcing, that is a separate `miss` (freeze/coma attack — see G-01).
7. Resume any suspended threads. Close the handle.
