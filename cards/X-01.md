# X-01

Test WMI event subscription detection.

1. Create a permanent WMI subscription:
   ```powershell
   $filter = Set-WmiInstance -Namespace root/subscription -Class __EventFilter -Arguments @{
     Name='EDR_TEST'; EventNameSpace='root/cimv2';
     QueryLanguage='WQL'; Query="SELECT * FROM __InstanceModificationEvent WITHIN 5 WHERE TargetInstance ISA 'Win32_Service' AND TargetInstance.Name='<agent_service>'"
   }
   $consumer = Set-WmiInstance -Namespace root/subscription -Class CommandLineEventConsumer -Arguments @{
     Name='EDR_TEST'; CommandLineTemplate='C:\TEMP\marker.bat'
   }
   Set-WmiInstance -Namespace root/subscription -Class __FilterToConsumerBinding -Arguments @{Filter=$filter; Consumer=$consumer}
   ```
2. Check the product log. If the subscription creation is detected, record `hold`.
3. If it persists silently, record `miss`.
4. Cleanup: `Get-WmiObject -Namespace root/subscription -Class __EventFilter -Filter "Name='EDR_TEST'" | Remove-WmiObject` (repeat for consumer and binding).
