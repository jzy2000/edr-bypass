# K-07

Test the depth of filter port client validation.

1. Copy a legitimate Windows binary and rename it to match the product's client: `copy C:\Windows\System32\notepad.exe C:\TEMP\<agent_name>.exe`.
2. From the renamed binary, attempt `FilterConnectCommunicationPort`.
3. If the connection succeeds (name-only check), record `miss`.
4. If rejected, try signing the binary with a self-signed cert matching the product's subject (L-03).
5. If that is also rejected (hash check), record `hold`.
6. Close the port handle.
