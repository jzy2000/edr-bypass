# N-04

Test whether heartbeats can be replayed or forged.

1. Capture agent heartbeat traffic with Wireshark or the MITM proxy from N-03.
2. Identify the heartbeat format (HTTP POST, protobuf, JSON, etc.).
3. Replay the captured heartbeat from a different process: `curl -X POST <cloud_endpoint> -d @heartbeat.bin -H "Content-Type: ..."`.
4. If the cloud accepts the replay (agent shows as healthy on the console), record `miss`.
5. If the cloud rejects the replay (nonce, timestamp, or authentication failure), record `hold`.
6. Also try: modify the heartbeat to report "I am fine" while the agent is actually stopped.
