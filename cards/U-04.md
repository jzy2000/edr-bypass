# U-04

Test whether the minifilter covers rename, link, and SetInformation operations.

1. Choose a protected file from `install_dir`.
2. **Rename via Win32**: `MoveFileExW(src, dst, MOVEFILE_REPLACE_EXISTING)`. Record success/error.
3. **Rename via native**: `NtSetInformationFile(handle, FileRenameInformation, {ReplaceIfExists=TRUE, FileName=dst})`. Record success/error.
4. **Hard link**: `CreateHardLinkW(linkPath, src, NULL)`. If it succeeds, the protected file now has a second name. Record.
5. **Symbolic link**: `mklink dst src` (requires dev mode or admin). Record.
6. **NtSetInformationFile(FileLinkInformation)**: create a hard link via native API. Record.
7. If all variants are blocked with STATUS_ACCESS_DENIED, record `hold`.
8. If any variant succeeds, record `miss` and name the variant.
9. Undo all renames and delete hardlinks. Restore from snapshot if a protected binary was moved.
