# P-09

Test whether the product detects reflective DLL loading or module stomping.

## Reflective Load

1. Read a DLL from disk into a buffer.
2. Allocate memory: `VirtualAlloc(NULL, imageSize, MEM_COMMIT|MEM_RESERVE, PAGE_READWRITE)`.
3. Copy headers and sections, fixing relocations and resolving imports manually.
4. Change protection: `VirtualProtect(codeSection, size, PAGE_EXECUTE_READ, &old)`.
5. Call `DllMain(base, DLL_PROCESS_ATTACH, NULL)`.
6. Check the product log. If detected (memory scan finds an unbacked executable region), record `hold`.

## Module Stomping

1. Load a legitimate signed DLL: `LoadLibraryA("amsi.dll")` (or any DLL the process doesn't actively use).
2. Find its `.text` section: parse the PE headers from `GetModuleHandleA`.
3. `VirtualProtect(.text, size, PAGE_READWRITE, &old)`.
4. Overwrite `.text` with your code.
5. `VirtualProtect(.text, size, PAGE_EXECUTE_READ, &old)`.
6. Execute. The code now runs from a signed module's address range.
7. Check the product log. If the product detects the .text mismatch, record `hold`. Otherwise, `miss`.

8. Terminate the test process.

Reference: [sRDI](https://github.com/monoxgas/sRDI), [Module Stomping](https://blog.f-secure.com/hiding-malicious-code-with-module-stomping/).
