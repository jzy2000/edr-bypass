# D-04

Test whether performance counter DLL registration is monitored.

1. Build a test DLL that exports `Open`, `Collect`, and `Close` (the perfmon interface). In `Open`, write a marker file.
2. Register it under an existing service's Performance key:
   ```
   reg add "HKLM\SYSTEM\CurrentControlSet\Services\<service>\Performance" /v Library /d "C:\TEMP\test_perf.dll" /f
   reg add "HKLM\SYSTEM\CurrentControlSet\Services\<service>\Performance" /v Open /d "OpenPerfData" /f
   reg add "HKLM\SYSTEM\CurrentControlSet\Services\<service>\Performance" /v Collect /d "CollectPerfData" /f
   reg add "HKLM\SYSTEM\CurrentControlSet\Services\<service>\Performance" /v Close /d "ClosePerfData" /f
   ```
3. Trigger a perf query: `typeperf "\<service>(*)\*" -sc 1` or open Performance Monitor.
4. If the marker file exists, the DLL was loaded — record `miss`.
5. If the product blocked the registry write or detected the DLL load, record `hold`.
6. Cleanup: delete the Performance subkey entries. Delete the DLL.
