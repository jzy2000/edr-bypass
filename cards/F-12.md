# F-12

Test whether the minifilter detects writes via memory-mapped views.

1. Choose a file the product monitors for content changes.
2. Open it: `CreateFileW(path, GENERIC_READ | GENERIC_WRITE, ...)`.
3. Map it: `CreateFileMappingW(hFile, NULL, PAGE_READWRITE, ...)`.
4. Get a view: `MapViewOfFile(hMapping, FILE_MAP_WRITE, ...)`.
5. Modify content: `memcpy(view + offset, payload, payloadLen)`.
6. Flush: `FlushViewOfFile(view, 0)`.
7. Unmap and close: `UnmapViewOfFile(view); CloseHandle(hMapping); CloseHandle(hFile)`.
8. No IRP_MJ_WRITE was generated. The modified pages go to disk via the lazy writer (IRP_MJ_WRITE from SYSTEM).
9. Read the product log. If the modification is detected, record `hold`. If not, record `miss`.
10. Restore the file.
