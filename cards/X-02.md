# X-02

Test scheduled task persistence detection.

1. Create a task: `schtasks /create /tn "EDR_PERSIST_TEST" /tr "C:\TEMP\persist.bat" /sc onstart /ru SYSTEM /f`.
2. Also try at-logon and at-idle triggers.
3. Check the product log for task creation events.
4. Reboot. Check if the task executes (look for the marker file).
5. If detected, record `hold`. If not, record `miss`.
6. `schtasks /delete /tn "EDR_PERSIST_TEST" /f`.
