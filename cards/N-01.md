# N-01

Test whether the product continues to protect locally when the cloud channel is cut.

1. From Session 1 admin, add an outbound block: `New-NetFirewallRule -DisplayName "EDR_BYPASS_TEST_BLOCK" -Direction Outbound -Program "%install_dir%\<agent_exe>" -Action Block`.
2. Wait 30 seconds for the agent to notice.
3. Perform the S-03 baseline: write a test file and check the product log. If the file write is still detected or blocked, local enforcement held.
4. Check the product log or UI for an isolation, offline, or connectivity-loss message.
5. If local enforcement continues and isolation is visible, record `hold`. If local detection stopped, record `miss`.
6. Cleanup: `Remove-NetFirewallRule -DisplayName "EDR_BYPASS_TEST_BLOCK"`. Wait for the agent to reconnect. Confirm via the product log.
