# C-04

Test whether the driver validates the source of commands.

Prerequisite: C-01 allows connection from a non-product process.

1. Reverse-engineer or guess the command format from the driver binary or companion DLL strings.
2. Send commands that should be privileged:
   a. "Disable anti-tamper" or "Set policy mode to off"
   b. "Add exclusion for C:\"
   c. "Terminate process PID=<target>"
   d. "Unload filter instance"
3. After each command, check whether it was executed:
   a. Can you now write to protected files?
   b. Is the exclusion active?
   c. Was the process terminated?
4. If all commands are rejected, record `hold`.
5. If any command executes from a non-product process, record `miss` and describe the impact.
6. Undo any changes.
