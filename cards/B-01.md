# B-01

Test whether the product prevents unauthorized uninstall.

1. From Session 1 admin, attempt the standard uninstall: `msiexec /x <product_msi>` or use Add/Remove Programs, or the product's own CLI uninstaller.
2. If a maintenance code, password, or cloud approval is required, attempt without it.
3. Also try: `sc stop <service>`, `sc delete <service>`, and manual file deletion from `install_dir`.
4. If all paths are refused, record `hold`. If any path succeeds in removing the product, record `miss`.
5. If uninstall succeeded, restore from the snapshot.
