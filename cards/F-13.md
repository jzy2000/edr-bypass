# F-13

Test whether exclusion paths can be widened from a low-privilege account.

1. As a standard user (T0), attempt to add an exclusion via the product's local UI or CLI.
2. If the product stores exclusions in the registry, attempt: `reg add "HKCU\SOFTWARE\<product>\Exclusions" /v Path1 /d "C:\" /f`.
3. If the product uses a local config file, attempt to write to it.
4. If any path succeeds, write a known-detected test file to the excluded path. If detection stops, record `miss`.
5. If all exclusion paths require admin or cloud approval, record `hold`.
6. Remove any added exclusions.
