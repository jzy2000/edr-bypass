# S-01

Verify the lab contract is ready before any probe.

1. Confirm `lab/local.yaml` exists and has all required keys: `scope`, `product_log`, `install_dir`, `data_dir`, `session1_admin`, `restore`, `os`, `hvci`.
2. Record agent, driver, and companion DLL file versions. On the target: `(Get-Item "$install_dir\*.exe","$install_dir\*.sys","$install_dir\*.dll" -ErrorAction SilentlyContinue).VersionInfo | Select FileName,FileVersion`.
3. Record OS build: `[System.Environment]::OSVersion.Version`.
4. Record HVCI / Memory Integrity: `(Get-CimInstance -ClassName Win32_DeviceGuard -Namespace root\Microsoft\Windows\DeviceGuard).VirtualizationBasedSecurityStatus`.
5. Take or confirm the restore snapshot named in `lab/local.yaml` `restore`.
