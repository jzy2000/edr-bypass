# C-05

Examine the strength of local IPC authentication.

1. Extract strings from the agent and companion binaries: `strings <agent_exe> | findstr /i secret key token auth`.
2. Search for the filter port connection context: the second argument to `FilterConnectCommunicationPort` is a context buffer. Find what the agent passes.
3. If the context is a static string (same across installations), record `miss` — any process knowing the string can connect.
4. If the context is derived from a machine-specific value (DPAPI, TPM, ephemeral key exchange), record `hold`.
5. For named pipes: check the pipe's DACL. If it allows Everyone or Authenticated Users, record `miss`.
6. For gRPC/REST: check if there is mTLS, a bearer token, or no auth at all.
