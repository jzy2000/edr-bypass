# R-04

Test whether the product's service registry keys are protected.

1. Attempt to change ImagePath: `reg add "HKLM\SYSTEM\CurrentControlSet\Services\<service>" /v ImagePath /d "C:\TEMP\evil.exe" /f`.
2. Attempt to change Start type to Disabled: `sc config <service> start= disabled`.
3. Attempt to change FailureActions to nothing: `sc failure <service> reset= 0 actions= ""`.
4. Attempt to remove required privileges: `reg delete "...\<service>" /v RequiredPrivileges /f`.
5. Also try the SCM API: `ChangeServiceConfigW` to change the binary path.
6. If all modifications are blocked, record `hold`.
7. If any succeed, record `miss` and name which values were changeable.
8. Restore all values. Restart the service.
