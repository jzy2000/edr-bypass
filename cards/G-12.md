# G-12

Test callback and dispatch integrity monitoring (combines K-04 and K-05 under a single gate).

1. From a lab kernel driver, corrupt each type of callback:
   a. Process-create notify (K-04)
   b. Image-load notify
   c. Registry callback
   d. Minifilter dispatch (K-05)
   e. ObRegisterCallbacks entries
2. After each corruption, wait 60 seconds.
3. If the product detects any corruption (alerts, re-registers, BSODs with an integrity check), record `hold`.
4. If any corruption is silent, record `miss`.
5. Restore from snapshot.
