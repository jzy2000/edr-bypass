# A-10

Gate: allocation vs loop bound.

For parser findings involving memory allocation:
1. Does the allocation size come from the same PE/file field as the loop iteration count?
2. If they come from different fields, an attacker can set a small allocation but a large loop count → heap overflow.
3. If they match, record this in the verdict.
4. If they don't match, file it as a separate finding.
