# O-05

Test detection of signed legitimate tools used for attacks.

1. Obtain lab copies of:
   a. ProcDump (Sysinternals): `procdump -ma lsass.exe C:\TEMP\lsass.dmp`
   b. Process Explorer (Sysinternals) in dump mode
   c. Other signed tools from the Microsoft-recommended block list
2. Execute each tool's attack function.
3. If the product detects or blocks the tool, record `hold`.
4. If the tool runs and completes its attack function without detection, record `miss`.
5. Delete the tools and dump files.
