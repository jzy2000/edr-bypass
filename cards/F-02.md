# F-02

Test minifilter file protection at different privilege levels.

## T0 (Standard User)
1. From a standard user session, attempt `echo test > "%install_dir%\probe.txt"`. Should fail due to NTFS ACLs alone.
2. Attempt on `data_dir` (which may have looser ACLs). Record whether the minifilter blocks independently of ACLs.
3. If T0 can write to `data_dir`, record `miss`.

## T2 (SYSTEM)
1. From a SYSTEM session (PsExec -s or a service), repeat F-01 operations.
2. If SYSTEM succeeds (SYSTEM is exempt from anti-tamper), document this as an expected exemption, not a miss.
3. Record: "SYSTEM exemption confirmed — admin-to-SYSTEM escalation is a prerequisite for file tampering."
4. If SYSTEM is also blocked, record `hold` (uncommon — most products exempt SYSTEM).

Clean up any test files.
