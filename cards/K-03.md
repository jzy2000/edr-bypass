# K-03

Test resilience to kernel-mode process termination.

Note: this requires a lab-owned kernel driver. The kernel write itself is not the finding — the question is whether the product detects and recovers.

1. Load a lab test driver.
2. From the driver, find the agent process: `PsLookupProcessByProcessId`.
3. Open a handle: `ZwOpenProcess(PROCESS_TERMINATE)` (kernel-mode, bypasses ObRegisterCallbacks).
4. Terminate: `ZwTerminateProcess(hProcess, STATUS_SUCCESS)`.
5. Wait 30 seconds. Check:
   - Did a watchdog restart the service?
   - Did a last-gasp alert fire to the cloud?
   - Did the driver detect the termination?
6. If auto-restart + alert fired, record `hold`.
7. If the agent stayed dead with no alert, record `miss`.
8. Restart the service manually.
