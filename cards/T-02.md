# T-02

Test local IPC bearer token replayability.

1. Monitor the local IPC channel (named pipe: use PipeList + IO Monitor; gRPC: capture loopback traffic).
2. Extract the bearer token or authentication context.
3. From a different process, replay the captured token to the same IPC endpoint.
4. If the endpoint accepts the replayed token, record `miss`.
5. If the endpoint rejects it (session-bound, nonce-based), record `hold`.
