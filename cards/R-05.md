# R-05

Audit which CmRegisterCallbackEx notify classes the product handles.

1. For each operation, attempt it on a product-protected key and record the result:
   - `RegSetValueExW` (RegNtPreSetValueKey)
   - `RegDeleteValueW` (RegNtPreDeleteValueKey)
   - `RegDeleteKeyW` (RegNtPreDeleteKey)
   - `NtRenameKey` (RegNtPreRenameKey)
   - `NtLoadKey` (RegNtPreLoadKey)
   - `RegRestoreKey` (RegNtPreRestoreKey)
   - `RegCreateKeyExW` (RegNtPreCreateKeyEx)
   - `NtSaveKey` (RegNtPreSaveKey)
2. Record each result in a table:

| Operation | Notify Class | Blocked? |
|---|---|---|
| SetValue | RegNtPreSetValueKey | ? |
| DeleteValue | RegNtPreDeleteValueKey | ? |
| ... | ... | ... |

3. If all relevant classes are blocked, record `hold`.
4. If any class is unhandled (operation succeeds), record `miss` and name the class.
5. Restore registry.
