# H-09

Test whether the injected sensor DLL can be unloaded.

1. Identify the product's injected DLL: `tasklist /m | findstr /i <sensor_dll>`. Launch a new `notepad.exe` and check if the DLL is loaded.
2. From within the target process (write a test program or inject via P-07):
   a. `GetModuleHandleA("<sensor_dll>")` to get the base address.
   b. `FreeLibrary(hModule)` — call it repeatedly (reference count may be >1).
   c. If FreeLibrary fails, try `LdrUnloadDll(hModule)` or `NtUnmapViewOfSection(GetCurrentProcess(), base)`.
3. After unloading, verify: `GetModuleHandleA("<sensor_dll>")` should return NULL.
4. Perform a detectable action (e.g., write a known-bad file). If the product still detects it (kernel sensor), record `hold`.
5. If the DLL stays unmapped and detection stops, record `miss`.
6. Restart the test process.
