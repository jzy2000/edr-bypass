# P-01

Baseline: confirm the process-create callback is active.

1. Compile a minimal test binary that does something observable (e.g., writes a marker file to `%TEMP%`).
2. From a standard user or Session 1 admin, run it with `CreateProcessW`.
3. Read the product log. If the process creation is logged with the image path, record `hold`.
4. If the process ran and nothing appeared in the log, the create callback may not be active — record `miss` or `inconclusive`.
5. Terminate the process and delete the binary.

This is the baseline for all P-* cards. If this card is `miss`, the product does not monitor process creation and all P-* evasion tests are `inconclusive`.
