# K-06

Test whether the product's driver can be unloaded.

## User-mode attempts (T1)
1. `fltmc unload <FilterName>`. Record result.
2. `sc stop <DriverService>`. Record result.
3. `NtUnloadDriver(L"\\Registry\\Machine\\System\\CurrentControlSet\\Services\\<driver>")`.

## Kernel-mode attempt (T3)
4. From a lab driver, call `ZwUnloadDriver`.
5. From a BYOVD driver (if K-01 was `miss`), attempt the same.

6. If all attempts fail (DriverUnload is NULL, or the driver refuses), record `hold`.
7. If any path succeeds, record `miss`.
8. Restore from snapshot if the driver was unloaded.
