# E-01

Test the file content parser's tolerance for fragmented writes.

1. Choose a payload the product detects (e.g., an EICAR test file, or a PE with known-bad characteristics). Confirm it is detected by writing it normally (one `WriteFile` call) — this is the baseline.
2. **Variant A (1-byte writes)**: Open a new destination. Write the same payload one byte at a time in a loop. Close. Check the log.
3. **Variant B (reverse order)**: Open a new destination. Set file size with `SetFilePointerEx` + `SetEndOfFile`. Write chunks from the end backward (offset N-1024, N-2048, ...). Close. Check the log.
4. **Variant C (non-zero start offset)**: Write 4096 bytes of junk first, then the payload starting at offset 4096. Close. Check the log.
5. **Variant D (interleaved)**: Write even bytes first, then odd bytes. Close. Check the log.
6. For each variant, record whether the product alerted. If all variants are detected, record `hold`. If any variant evades, record `miss` and name the variant.
7. Answer the variant questions in the verdict.
8. Delete all test files.
