# P-03

Test whether the product compares the image section to the on-disk file content.

1. Write a PE payload (e.g., an infinite-loop stub) to a temporary file via `NtCreateFile` + `NtWriteFile`.
2. Create an image section: `NtCreateSection(SEC_IMAGE)` from the file handle. The section now references the payload.
3. Overwrite the file content with a benign binary (e.g., `calc.exe`): `NtWriteFile` to the same handle, then `NtSetInformationFile(FileEndOfFileInformation)` to set the new size.
4. Flush and close: `FlushFileBuffers` then `NtClose` the file handle.
5. Create a process from the section: `NtCreateProcessEx`. The process image is the payload, but on-disk the file is now `calc.exe`.
6. Create the initial thread: `NtCreateThreadEx`.
7. Read the product log. If it references `calc.exe` (the on-disk content) rather than the actual payload, record `miss`. If it detects the mismatch or blocks the process, record `hold`.
8. Terminate the process and delete the file.

Reference: [Process Herpaderping — jxy-s](https://github.com/jxy-s/herpaderping).
