# G-04

Audit the product's allowlist for abuse potential.

1. Extract the allowlist: from the product config, registry, or binary strings.
2. For each allowlist entry:
   a. If it's a path, check if any attacker-writable location matches (e.g., `C:\Users\*`, `%TEMP%`).
   b. If it's a signer, check if the certificate can be obtained (public CA, self-signed match).
   c. If it's a hash, check if it matches any dual-use tool.
3. If an attacker can place a payload in an allowlisted location, record `miss`.
4. If all entries are tightly scoped, record `hold`.
