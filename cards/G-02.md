# G-02

Test minifilter altitude collision.

1. `fltmc instances` — note the product's altitude.
2. Build a test minifilter with the same altitude in its INF file.
3. Load: `fltmc load TestFilter`. The filter manager should reject duplicate altitudes on the same volume.
4. Try adjacent altitudes (±1). If the test filter attaches at a higher altitude, it sees IRPs before the product.
5. If the product detects the altitude conflict, record `hold`.
6. If the product's instance fails to attach or is bypassed, record `miss`.
7. `fltmc unload TestFilter`. Revert.
