# B-07

Test early-boot service interference (lifecycle view of L-05).

1. Create a service in the same load order group as the product agent, with a dependency that makes it start first.
2. In the rogue service:
   a. Lock critical files the agent needs.
   b. Pre-occupy named objects (mutexes, events, pipes).
   c. Saturate the filter port with connections.
3. Reboot.
4. If the agent starts correctly despite the interference, record `hold`.
5. If the agent fails to start or enters a degraded state, record `miss`.
6. Delete the rogue service. Revert.
