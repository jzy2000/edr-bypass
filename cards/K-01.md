# K-01

Test whether the product blocks a known-vulnerable driver.

1. Confirm HVCI is OFF for this test (HVCI blocks many drivers at the OS level; that is K-02).
2. Obtain a copy of a known-vulnerable, Microsoft-signed driver from the [Microsoft recommended block list](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/windows-defender-application-control/design/microsoft-recommended-driver-block-rules). Use only a driver you have in your lab — do not download from an untrusted source.
3. Install: `sc create TestVulnDrv type= kernel binPath= C:\TEMP\<driver>.sys`.
4. Start: `sc start TestVulnDrv`.
5. If the start fails with an error and the product log shows a block event, record `hold`.
6. If the driver loads (verify with `sc query TestVulnDrv` showing RUNNING), record `miss`.
7. Cleanup: `sc stop TestVulnDrv & sc delete TestVulnDrv`. Delete the `.sys` file.
