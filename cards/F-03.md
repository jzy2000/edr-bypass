# F-03

Test minifilter instance integrity.

## Altitude collision (T1)
1. `fltmc instances` to list current instances and altitudes.
2. Attempt to register a filter at the same altitude: build a minimal minifilter driver, set the same altitude in the INF.
3. `fltmc load TestFilter`. If the product detects the collision or the OS rejects it, record `hold`.

## Instance detach (T3 — requires kernel driver)
1. From a test kernel driver, walk the device stack: `IoGetAttachedDeviceReference`.
2. Find the product's filter device object.
3. Call `IoDetachDevice` to remove it from the stack.
4. Perform a file write to a protected path. If the write succeeds (filter no longer intercepts), record `miss`.
5. If the product detects the detach or re-attaches, record `hold`.
6. Unload the test driver. Restore from snapshot.
