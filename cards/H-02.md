# H-02

Test whether a leftover PROCESS_CREATE_THREAD right lets an attacker kill the agent.

Prerequisite: run H-01 first. If PROCESS_CREATE_THREAD (0x0002) was stripped, this card is `inconclusive` — the product already defended.

1. From Session 1 admin, open the agent process: `OpenProcess(PROCESS_CREATE_THREAD | PROCESS_QUERY_INFORMATION | PROCESS_VM_OPERATION | PROCESS_VM_WRITE, FALSE, pid)`.
2. Resolve `ExitProcess`: `GetProcAddress(GetModuleHandleA("kernel32.dll"), "ExitProcess")`.
3. `CreateRemoteThread(hProcess, NULL, 0, (LPTHREAD_START_ROUTINE)exitAddr, (LPVOID)1, 0, NULL)`.
4. Wait 5 seconds. Check if the agent process is still running: `sc query <service>`.
5. If the thread creation failed (handle lacked the right), record `hold`.
6. If the thread was created but the agent restarted within 10 seconds (watchdog), record `hold` with a note about the watchdog.
7. If the agent died and did not restart, record `miss`.
