# T-01

Test whether the product's identity checks can be fooled by token impersonation.

1. Get the agent's process token: `OpenProcessToken(hAgent, TOKEN_DUPLICATE | TOKEN_QUERY, &hToken)` (requires PROCESS_QUERY_INFORMATION on the agent — check H-01 first).
2. If the agent runs as a unique service account (not SYSTEM), duplicate: `DuplicateTokenEx(hToken, MAXIMUM_ALLOWED, NULL, SecurityImpersonation, TokenImpersonation, &hImpToken)`.
3. Impersonate: `SetThreadToken(NULL, hImpToken)` or `ImpersonateLoggedOnUser(hImpToken)`.
4. Re-run H-01: `OpenProcess(PROCESS_ALL_ACCESS, FALSE, agentPid)`. If GrantedAccess is now higher than before, the ObCallback checks the token SID — record `miss`.
5. Re-run C-01: `FilterConnectCommunicationPort(portName)`. If the connection now succeeds, the port checks the token — record `miss`.
6. Re-run F-01: attempt a write to `install_dir`. If the write now succeeds, the minifilter checks the token — record `miss`.
7. If none of the retries gained additional access, record `hold`.
8. `RevertToSelf()`. Close all handles.

Note: if the agent runs as SYSTEM, you already have SYSTEM via WinRM and this card is `inconclusive`. Test with a scheduled task running as the agent's service account instead.
