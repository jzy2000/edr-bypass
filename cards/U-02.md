# U-02

Test whether the product's file sensor covers memory-mapped writes.

1. Create a source file with known content (e.g. 4096 bytes of `0x41`).
2. **Path A (WriteFile)**: `CreateFile(destA, GENERIC_WRITE) → WriteFile → CloseHandle`.
3. **Path B (NtWriteFile)**: `NtCreateFile(destB) → NtWriteFile → NtClose`. Use the native API directly.
4. **Path C (mapped view)**: `CreateFile(destC, GENERIC_READ|GENERIC_WRITE) → CreateFileMapping(PAGE_READWRITE) → MapViewOfFile(FILE_MAP_WRITE) → memcpy(view, data, 4096) → FlushViewOfFile → UnmapViewOfFile → CloseHandle`.
5. All three destinations should have identical content. Verify with `fc /b destA destC`.
6. Read the product log. Search for entries referencing each destination.
7. If all three appear, record `hold`. If the mapped view write is missing, record `miss`.
8. Delete all three files.
