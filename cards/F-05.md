# F-05

Test whether Cloud Filter (cldflt.sys) can redirect the product's file reads.

1. Check that `cldflt.sys` is loaded: `fltmc filters | findstr /i cldflt`.
2. Register a sync root on the product's data directory: `CfRegisterSyncRoot`.
3. Convert an existing product file to a placeholder: `CfConvertToPlaceholder`.
4. Set up a fetch callback that returns attacker-controlled content.
5. When the product reads the file, it will receive the attacker's content instead.
6. Check the product log. If it processes the attacker content, record `miss`.
7. If the product validates the content or reads from a cached/pinned copy, record `hold`.
8. Unregister the sync root. Remove placeholders.
