# A-11

Gate: TOCTOU.

For every finding involving a check-then-use pattern:
1. Is the checked value re-read after the check? (Common in mapped views, shared memory, registry)
2. If the value is re-read from a shared source, an attacker can change it between check and use.
3. Document whether TOCTOU applies. If it does, file a separate finding.
