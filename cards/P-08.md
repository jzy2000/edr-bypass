# P-08

Test whether the product detects APC-based injection.

## Early Bird variant

1. Create a process suspended: `CreateProcessW("svchost.exe", ..., CREATE_SUSPENDED)`.
2. Allocate memory in the target: `VirtualAllocEx`.
3. Write shellcode (benign marker).
4. Queue APC to the main thread before it has run: `QueueUserAPC(allocAddr, hThread, 0)`.
5. Resume: `ResumeThread(hThread)`. The APC runs before the entry point.
6. Check the product log. If detected, record `hold`. If not, record `miss`.

## Alertable thread variant

1. Find a thread in a running process that calls `SleepEx`, `WaitForSingleObjectEx`, or `MsgWaitForMultipleObjectsEx` with `bAlertable=TRUE`.
2. Open the process and allocate+write as above.
3. `QueueUserAPC(allocAddr, hAlertableThread, 0)`.
4. The APC will execute when the thread enters an alertable wait.
5. Check the product log.

6. Terminate the target processes.
