# L-01

Record the agent's protection level.

1. Open the agent: `OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, FALSE, pid)`.
2. `NtQueryInformationProcess(ProcessProtectionInformation)` returns `PS_PROTECTION`:
   - `Type`: 0 = None, 1 = ProtectedLight, 2 = Protected
   - `Signer`: 0 = None, 1 = Authenticode, 2 = CodeGen, 3 = Antimalware, 4 = Lsa, 5 = Windows, 6 = WinTcb, 7 = WinSystem
3. Record the Type and Signer values.
4. If Type == 0 (not PPL), check whether the product relies solely on ObRegisterCallbacks for handle protection. Not PPL alone is not a `miss` — many products protect themselves without PPL — but it means handle-stripping is the only barrier to process tampering.
5. If Type >= 1, record `hold` and note the signer level. Higher signer levels are harder to bypass.
6. Record the result. No cleanup needed.

Note: PPL bypass techniques (debug object, vulnerable AM signer DLL, `PPLdump`) are tested in L-02 through L-05.
