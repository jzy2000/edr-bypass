# A-07

Gate: variant questions.

For every parser finding:
1. Address class: is the corrupted value a kernel address, a user VA, or a file offset?
2. Unsigned size: is the size field signed or unsigned? What happens at MAX_UINT?
3. 32/64 sibling: does the same parser exist in both 32-bit and 64-bit? Do they share bounds checks?
4. Where does a successful read go? (user-visible buffer, pool, stack, discarded)
5. If any question is unanswered, answer it and update the verdict.
