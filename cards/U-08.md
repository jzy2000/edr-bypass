# U-08

Test whether sleep-time memory obfuscation evades periodic scanning.

1. Build a test program that:
   a. Allocates RWX memory with `VirtualAlloc`.
   b. Writes a known-detected pattern (EICAR or a custom signature the product detects).
   c. Confirms the product detects it (baseline).
2. Modify the program to add sleep obfuscation:
   a. Before sleeping, XOR-encrypt the payload region and change protection to RW (not executable).
   b. Optionally encrypt the stack with `RtlEncryptMemory` (or a custom XOR).
   c. Sleep for 60 seconds.
   d. On wake, decrypt the payload, restore RWX, and execute.
3. Run the obfuscated version. Let it complete 3 sleep/wake cycles.
4. Read the product log. If the payload is detected during any cycle, record `hold`.
5. If the payload survives all cycles, record `miss`.
6. Terminate the test process.

Reference: [Ekko sleep obfuscation](https://github.com/Cracked5pider/Ekko), [Foliage](https://github.com/SecIdiot/FOLIAGE).
