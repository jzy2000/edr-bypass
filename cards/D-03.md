# D-03

Test whether the product detects COM InprocServer32 hijacking.

1. Choose a COM CLSID that a system or privileged process uses. Common candidates:
   - `{BDB57FF2-79B9-4205-9447-F5FE85F37312}` (EventViewer/MMC)
   - `{0A29FF9E-7F9C-4437-8B11-F424491E3931}` (shell COM objects)
   Use ProcMon to find CLSIDs the product loads: filter `RegQueryValue` for `InprocServer32`.
2. Create a test DLL (writes marker file in DllMain).
3. Set the HKCU override: `reg add "HKCU\Software\Classes\CLSID\{<clsid>}\InprocServer32" /ve /d "C:\TEMP\test_com.dll" /f`.
4. Also set the threading model: `reg add "HKCU\Software\Classes\CLSID\{<clsid>}\InprocServer32" /v ThreadingModel /d Both /f`.
5. Trigger the COM load (e.g., open Event Viewer, or call `CoCreateInstance` from a test program).
6. If the marker file exists, the hijack succeeded — record `miss`.
7. If the product blocked or alerted, record `hold`.
8. Cleanup: `reg delete "HKCU\Software\Classes\CLSID\{<clsid>}" /f`. Delete the test DLL.
