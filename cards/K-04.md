# K-04

Test whether the product detects callback removal.

1. From a lab kernel driver, locate the callback arrays:
   - `PspCreateProcessNotifyRoutine` (process creation)
   - `PspLoadImageNotifyRoutine` (image load)
   - `CmpCallbackListHead` (registry)
   - `CallbackListHead` in the `ObCallbackType` for process/thread
2. Find the product's callback entries (match the callback function address to the driver's address range).
3. Zero out or unlink the entries.
4. Perform actions the product should detect (file write, process create, registry change).
5. If the product detects the removal (integrity check, re-registration, alert), record `hold`.
6. If detection stops silently, record `miss`.
7. Restore from snapshot (callback corruption requires clean state).
