# T-05

Audit binary information leakage. This is a hygiene finding, not a bypass.

1. `strings <agent_exe> | findstr /i "\\build\\ \\src\\ \\users\\ @"`.
2. `dumpbin /headers <agent_exe>` — look for PDB paths.
3. Check for embedded SBOM (Software Bill of Materials) data.
4. Check for internal module names, employee names, or ticket IDs.
5. If internal paths or debug info are present, record `miss` (hygiene).
6. If the binary is clean, record `hold`.

Record separately from bypass findings.
