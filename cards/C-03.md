# C-03

Test the driver's robustness against malformed messages.

Prerequisite: C-01 must allow connection, or use a different approach to send messages.

1. Connect to the port: `FilterConnectCommunicationPort`.
2. Send messages with:
   a. Zero-length buffer: `FilterSendMessage(hPort, NULL, 0, reply, sizeof(reply), &ret)`.
   b. Maximum-length buffer (64 KB of random data).
   c. Buffer with a valid header but corrupted body.
   d. Buffer with an unknown command type.
   e. Rapidly repeated messages (1000 in a loop).
3. After each send, check: did the system BSOD? Is the driver still loaded? Is the agent still running?
4. If all malformed messages are handled gracefully (error returned, no crash), record `hold`.
5. If any message causes a BSOD or agent crash, record `miss` (or a crash finding).
6. Revert from snapshot if needed.
