# B-08

Test for TOCTOU in config file verification.

1. Identify the product's config file and its verification mechanism.
2. Set up a bind link or rapid rename loop:
   a. Write a valid config to the expected path.
   b. After the driver verifies it, rapidly replace it with a modified config.
3. Use bind links (F-04) to toggle between the real and modified config.
4. If the driver uses the modified config after verifying the original, record `miss`.
5. If the driver re-reads and re-verifies, or reads atomically, record `hold`.
6. Restore the config file.
