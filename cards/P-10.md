# P-10

Test whether sibling processes are a trust bypass vector.

1. Enumerate the product's processes: `Get-Process | Where-Object {$_.Path -like "*<install_dir>*"}`. Look for UI, updater, tray, or helper processes beyond the main agent/service.
2. If a sibling exists (e.g., a tray icon process running as the logged-in user), open it: `OpenProcess(PROCESS_ALL_ACCESS)`.
3. If the handle is granted (sibling may not be protected by ObRegisterCallbacks), inject a thread that:
   a. Opens the main agent process: `OpenProcess(PROCESS_ALL_ACCESS)`. Record `GrantedAccess`.
   b. Attempts to write to `install_dir`: `CreateFile → WriteFile`.
   c. Attempts to modify a protected registry key.
4. If the injected code in the sibling gets higher access than a standalone admin process (H-01), the driver trusts the sibling's image — record `miss`.
5. If the sibling gets the same restricted access, record `hold`.
6. Terminate injected threads. Restart the service if needed.
