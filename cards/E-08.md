# E-08

Test whether the product detects IAT manipulation.

1. Load a legitimate DLL.
2. Overwrite its IAT entries with custom function pointers (redirect API calls).
3. Or: load a PE via reflective loading (P-09) with a modified import table that points to different functions.
4. Check if the product detects the IAT mismatch between disk and memory.
5. If detected, record `hold`. If not, record `miss`.
6. Terminate test process.
