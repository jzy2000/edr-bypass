# E-03

Test whether rename triggers a re-scan.

1. Write a known-detected payload with a `.txt` extension (not typically scanned for PE content).
2. Confirm it is not detected as `.txt`.
3. Rename to `.exe`: `ren payload.txt payload.exe`.
4. If the product detects the file after rename, record `hold`.
5. If the renamed file is not scanned (cached as clean from the .txt write), record `miss`.
6. Delete test files.
