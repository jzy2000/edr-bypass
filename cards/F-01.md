# F-01

Test the minifilter file-write guard from a non-exempt admin.

1. From a Session 1 admin cmd (not WinRM, not SYSTEM), attempt to create a file in `install_dir`: `echo test > "%install_dir%\probe.txt"`. Record the NTSTATUS or Win32 error.
2. Attempt to delete an existing product binary: `del "%install_dir%\<any_dll>"`. Record the error.
3. Attempt to rename: `ren "%install_dir%\<any_dll>" renamed.bak`. Record the error.
4. Repeat each operation on `data_dir`.
5. Read the product log. If the operations returned ACCESS_DENIED and the log shows a block or tamper event, record `hold`. If any operation succeeded silently, record `miss`.
6. Undo: delete `probe.txt` if it was created. If a rename succeeded, rename it back or restore from snapshot.

Note: if the only reason the write failed is a Windows ACL (not TrustedInstaller, not the minifilter), the driver did not enforce anything. That is a miss even though the write failed.
