# P-05

Test whether the product detects process doppelgänging.

Note: Microsoft blocked SEC_IMAGE from transacted files starting in Windows 10 1809. If the target OS returns STATUS_NOT_SUPPORTED, record `inconclusive`.

1. Create a transaction: `NtCreateTransaction`.
2. Open a file transacted: `NtCreateFile` with the transaction handle (use `RtlSetCurrentTransaction` or pass the handle via extended attributes).
3. Write a PE payload into the transacted file.
4. Create an image section: `NtCreateSection(SEC_IMAGE)` from the transacted file handle.
5. If step 4 fails with STATUS_NOT_SUPPORTED, record `inconclusive` and stop.
6. Rollback the transaction: `NtRollbackTransaction`. The file reverts — but the section is still valid.
7. Create a process: `NtCreateProcessEx`. Create the thread: `NtCreateThreadEx`.
8. The process-create callback fires. The backing file is rolled back / nonexistent.
9. Read the product log. If it detects the anomaly, record `hold`. If the process runs undetected, record `miss`.
10. Terminate the process.

Reference: [Process Doppelgänging — enSilo/Fortinet](https://www.blackhat.com/docs/eu-17/materials/eu-17-Liberman-Lost-In-Transaction-Process-Doppelganging.pdf).
