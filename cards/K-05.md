# K-05

Test minifilter dispatch pointer integrity.

1. From a lab kernel driver, locate the product's `FLT_FILTER` structure.
2. Find the `FLT_OPERATION_REGISTRATION` array (pre/post callbacks for each IRP major function).
3. Replace the PreOperation callback for IRP_MJ_CREATE or IRP_MJ_WRITE with a no-op function.
4. Attempt a file write to a protected path. If it succeeds (the filter no longer intercepts), record `miss`.
5. If the product detects the patch (integrity timer, PatchGuard extension, or self-check), record `hold`.
6. Restore from snapshot.
