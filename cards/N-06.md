# N-06

Test ransomware detection in offline mode.

1. Block cloud connectivity: `New-NetFirewallRule -DisplayName EDR_OFFLINE_TEST -Direction Outbound -Program "%install_dir%\<agent_exe>" -Action Block`.
2. Wait 60 seconds for the agent to enter offline mode.
3. Perform ransomware-like operations:
   a. Mass rename: rename 100 files to `.encrypted` extension.
   b. Mass overwrite: overwrite file contents with random data.
   c. Mass delete: delete the renamed files.
4. Check the product log for local detection.
5. If the product blocked or alerted on the ransomware behavior locally, record `hold`.
6. If the operations completed without detection, record `miss`.
7. Remove the firewall rule. Restore from snapshot.
