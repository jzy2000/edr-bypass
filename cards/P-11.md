# P-11

Test whether creating a product process from a non-product parent grants excessive access.

1. From a Session 1 admin process (not the product), create: `CreateProcessW("<install_dir>\\<agent_exe>", NULL, NULL, NULL, FALSE, CREATE_SUSPENDED, ...)`.
2. The return value includes `hProcess` — this is the parent handle to the new process.
3. Inspect `hProcess` granted access: `NtQueryObject(hProcess, ObjectBasicInformation)`.
4. Check for invasive rights:
   - PROCESS_VM_WRITE (0x0020)
   - PROCESS_VM_OPERATION (0x0008)
   - PROCESS_TERMINATE (0x0001)
   - PROCESS_CREATE_THREAD (0x0002)
5. If the ObRegisterCallbacks stripped the parent handle on creation, these bits should be absent — record `hold`.
6. If the parent handle has full rights to the product process, an attacker who creates a suspended product process can then inject code into it — record `miss`.
7. Terminate the suspended process: `TerminateProcess(hProcess, 0)`.
