# G-06

Test hash cache poisoning via alternate data streams.

1. Create a clean file: `echo clean > C:\TEMP\test.exe`.
2. Write an ADS: `echo aux > C:\TEMP\test.exe:aux`. This may trigger a scan of the file.
3. Check the product log — if the file is now cached as "clean".
4. Replace the default stream content with a known-bad payload.
5. Open or execute `C:\TEMP\test.exe`.
6. If the product re-scans, record `hold`. If it uses the cached result, record `miss`.
7. Delete test files.
