# G-08

Test whether local policy edits are enforced without cloud validation.

1. Locate the local policy database (T-04).
2. If decryptable, modify a policy value (e.g., change a detection rule, add an exclusion).
3. Restart the agent to load the modified policy.
4. If the agent accepts the local change without cloud re-validation, record `miss`.
5. If the agent detects the unsigned change and reverts or alerts, record `hold`.
6. Restore the database.
