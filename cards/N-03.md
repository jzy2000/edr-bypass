# N-03

Test whether the agent pins its TLS certificates.

1. Generate a rogue CA: `openssl req -x509 -newkey rsa:2048 -keyout ca.key -out ca.crt -days 365 -nodes`.
2. Import the CA into the machine store: `certutil -addstore Root ca.crt`.
3. Set up a MITM proxy (e.g., `mitmproxy --mode transparent --set ssl_insecure`) that uses the rogue CA.
4. Redirect the agent's traffic through the proxy (hosts file, DNS, or WFP redirect).
5. If the agent rejects the connection (pinned certificate doesn't match), record `hold`.
6. If the agent connects through the proxy and sends telemetry, record `miss`.
7. Remove the rogue CA: `certutil -delstore Root <serial>`. Restore DNS/hosts.
