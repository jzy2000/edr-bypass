# E-07

Test when the product captures the command line.

1. Create a process suspended: `CreateProcessW("cmd.exe", "/c echo REAL_COMMAND", ..., CREATE_SUSPENDED)`.
2. Overwrite the PEB command line with `WriteProcessMemory`: replace with "svchost.exe -k netsvcs".
3. Resume the process.
4. Read the product log. If it shows "REAL_COMMAND" (captured at creation from kernel), record `hold`.
5. If it shows "svchost.exe -k netsvcs" (read from PEB later), record `miss`.
6. Terminate test processes.
