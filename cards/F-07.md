# F-07

Test whether a boot-time file rename bypasses the minifilter.

1. From Session 1 admin, attempt: `MoveFileEx "%install_dir%\<a_product_dll>" "%install_dir%\<a_product_dll>.bak" /Y` with the `MOVEFILE_DELAY_UNTIL_REBOOT` flag (in C: `MoveFileExW(src, dst, MOVEFILE_DELAY_UNTIL_REBOOT)`). This writes to `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\PendingFileRenameOperations`.
2. If the write to PendingFileRenameOperations was blocked by the registry callback, record `inconclusive` — the product prevented the setup.
3. If the write succeeded, reboot the machine.
4. After reboot, check if the file was renamed. If it was, and the product does not alert or repair, record `miss`.
5. If the file is still in place, or it was renamed but the product immediately repaired it and logged a tamper event, record `hold`.
6. Restore the file from the snapshot. Clean `PendingFileRenameOperations` if any entries remain.
