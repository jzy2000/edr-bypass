# P-02

Test whether the product detects a process whose backing file was deleted before the image callback fires.

1. Create a temporary file with `NtCreateFile`.
2. Set `FileDispositionInformation.DeleteFile = TRUE` via `NtSetInformationFile` — the file is now delete-pending but the handle is open.
3. Write a minimal PE (e.g., an infinite-loop stub: `0xEB 0xFE` at entry) into the file.
4. Create an image section: `NtCreateSection(SEC_IMAGE)` from the file handle.
5. Close the file handle — the file is deleted from disk, but the section is valid.
6. Create a process from the section: `NtCreateProcessEx`.
7. Create the initial thread: `NtCreateThreadEx`. The process-create callback fires now.
8. Read the product log. If the create is blocked or the product alerts on a missing/deleted backing file, record `hold`. If the process runs silently, record `miss`.
9. Terminate the process.

Reference: [Process Ghosting — Elastic](https://www.elastic.co/blog/process-ghosting-a-new-executable-image-tampering-attack).
