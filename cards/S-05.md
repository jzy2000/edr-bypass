# S-05

Record HVCI state and plan separate runs.

1. Query HVCI: `(Get-CimInstance -ClassName Win32_DeviceGuard -Namespace root\Microsoft\Windows\DeviceGuard).VirtualizationBasedSecurityStatus`. Values: 0=Off, 1=Configured, 2=Running.
2. Also check: `bcdedit /enum {current} | findstr hypervisorlaunchtype`.
3. Record: `msinfo32` → Virtualization-based security, Credential Guard, HVCI.
4. If HVCI is on, all kernel cards (K-01 through K-08) that involve loading unsigned drivers will fail at the OS level — that is not a product `hold`, it is an OS gate. Run those cards with HVCI off too.
5. Create a test plan with two columns:
   - Column A: HVCI on (record which K-* cards are OS-blocked)
   - Column B: HVCI off (test whether the product blocks independently)
6. This card establishes the plan. The actual HVCI toggle is done before each K-* card run.
