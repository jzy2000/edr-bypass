# K-08

Test whether the hash/scan cache can be poisoned.

1. Write a clean file and trigger a scan (open it, execute it, or wait for the on-access scanner).
2. Confirm it is allowed (check the product log for a clean scan result).
3. Replace the file content with a known-bad payload:
   a. `NtSetInformationFile(FileEndOfFileInformation)` to truncate.
   b. `WriteFile` to write the bad content.
4. Open or execute the file again.
5. If the product re-scans and catches the bad content, record `hold`.
6. If the cached clean result is reused and the bad file is allowed, record `miss`.
7. Delete test files.
