# E-04

Test hash catalog validation robustness.

1. Identify the product's hash catalog or allowlist/blocklist storage.
2. Replace it with:
   a. An empty file.
   b. A truncated file (first half only).
   c. A file with a valid header but corrupted entries.
3. Trigger a scan or restart the agent.
4. If the product falls back gracefully (denies unknown, or re-fetches from cloud), record `hold`.
5. If the product allows everything (empty allowlist = allow all) or crashes, record `miss`.
6. Restore the catalog.
