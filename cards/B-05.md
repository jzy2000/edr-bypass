# B-05

Test whether the upgrade path can be hijacked.

1. Find the product's update mechanism (MSI, custom installer, auto-update service).
2. Download or capture a legitimate update package.
3. Modify the package (replace a DLL or change a script).
4. Attempt the upgrade: `msiexec /i modified_package.msi` or invoke the updater with the crafted package.
5. If the updater rejects the package (signature mismatch), record `hold`.
6. If the updater installs the modified package, record `miss`.
7. Restore from snapshot.
