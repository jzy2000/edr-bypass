# H-04

Test whether duplicating and closing the agent's handles destabilizes it.

Prerequisite: run H-01. If PROCESS_DUP_HANDLE (0x0040) was stripped, record `inconclusive`.

1. Open the agent: `OpenProcess(PROCESS_DUP_HANDLE, FALSE, pid)`.
2. Use `NtQuerySystemInformation(SystemHandleInformation)` to enumerate handles owned by the agent PID.
3. For each handle, `DuplicateHandle(hAgent, handle, GetCurrentProcess(), &dup, 0, FALSE, DUPLICATE_CLOSE_SOURCE)`. The `DUPLICATE_CLOSE_SOURCE` flag closes the handle in the agent.
4. Target handles to named pipes, events, mutexes, and file objects that look like log files or communication channels.
5. After closing ~10 handles, wait 30 seconds. Check `sc query <service>`.
6. If the agent stays up and keeps enforcing (re-run S-03 baseline), record `hold`.
7. If the agent crashed or stopped enforcing, record `miss`.
8. Restart the service if needed.

Warning: this test can destabilize the agent. Be prepared to restore from the snapshot.
