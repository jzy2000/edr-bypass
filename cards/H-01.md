# H-01

Test whether ObRegisterCallbacks strips invasive handle rights.

1. From a Session 1 admin process (not WinRM, not the product image), find the agent PID: `(Get-Process -Name <agent_process>).Id`.
2. Call `OpenProcess(PROCESS_ALL_ACCESS, FALSE, pid)`. If it returns NULL, record `GetLastError`.
3. If a handle is returned, inspect `GrantedAccess`. Use `NtQueryObject(ObjectBasicInformation)` or compile a small C program that prints `OBJECT_BASIC_INFORMATION.GrantedAccess`.
4. Compare `GrantedAccess` against the requested `0x1FFFFF`. List which bits are present and which were stripped.
5. Key rights to check:

| Right | Value | Stripped? |
|---|---|---|
| PROCESS_TERMINATE | 0x0001 | should be |
| PROCESS_CREATE_THREAD | 0x0002 | check |
| PROCESS_VM_OPERATION | 0x0008 | should be |
| PROCESS_VM_WRITE | 0x0020 | should be |
| PROCESS_VM_READ | 0x0010 | check |
| PROCESS_SUSPEND_RESUME | 0x0800 | should be |
| PROCESS_DUP_HANDLE | 0x0040 | check |

6. If invasive bits are stripped, record `hold`. If any are present, record `miss` and name which right was left.
7. Close the handle.
