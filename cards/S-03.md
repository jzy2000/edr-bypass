# S-03

Verify the product is running and detecting before you test evasion.

1. Write a known-detected test file into `data_dir` using a plain Win32 call: `echo test > %data_dir%\oracle_check.txt`.
2. Read the product log from `lab/local.yaml` `product_log`. Search for an entry referencing the write.
3. If the log contains the expected entry, record `hold`. If not, the product may be off or the log path is wrong — record `inconclusive` and stop the campaign.
4. Delete `oracle_check.txt`.
