# R-02

Test the registry protection timing window.

1. Reboot the target (or revert to snapshot and boot).
2. Immediately (within the first 30 seconds), before the agent has connected to the cloud, attempt R-01 registry writes.
3. Also attempt during boot: create a scheduled task that runs at startup and writes to the product's registry key.
4. If the writes succeed during the window but fail after the agent connects, record `miss` — there is a policy-off gap.
5. If the writes are blocked even before cloud check-in (driver enforces from boot), record `hold`.
6. Restore registry values.
