# F-06

Test whether the product monitors alternate data streams.

1. Create a benign file: `echo clean > C:\TEMP\testfile.txt`.
2. Write a payload to an ADS: `echo payload > C:\TEMP\testfile.txt:hidden`.
3. Also write via native API: `NtCreateFile` with the stream name `testfile.txt:native_ads:$DATA`.
4. Read the product log. If the ADS writes appear, record `hold`.
5. If only the main stream write is visible, record `miss`.
6. Test execution from ADS: `wscript C:\TEMP\testfile.txt:script.vbs` (write a VBS to the ADS first).
7. Delete the test file (this removes all streams).
