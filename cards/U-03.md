# U-03

Test whether the product normalizes all path forms before matching.

1. Identify a protected file from `install_dir` (e.g. a product DLL).
2. Try to open or rename it using each path variant:
   - DOS path: `C:\Program Files\<product>\file.dll`
   - Win32 long path: `\\?\C:\Program Files\<product>\file.dll`
   - NT device path: `\??\C:\Program Files\<product>\file.dll` (via NtCreateFile)
   - Short name: get it with `GetShortPathNameW`, then use `C:\PROGRA~1\...`
   - Junction: `mklink /J C:\TEMP\jlink "C:\Program Files\<product>"`, then access `C:\TEMP\jlink\file.dll`
3. For each variant, attempt a rename: `ren <path> <path>.bak`.
4. If all attempts are blocked by the minifilter, record `hold`.
5. If any path variant succeeds in renaming the file, record `miss` and name the variant.
6. Remove junctions: `rmdir C:\TEMP\jlink`. Rename any moved files back.
