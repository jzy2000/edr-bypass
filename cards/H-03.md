# H-03

Test whether an attacker can read secrets from the agent's process memory.

Prerequisite: run H-01 first. If PROCESS_VM_READ (0x0010) was stripped, this card is `inconclusive`.

1. Open the agent with `OpenProcess(PROCESS_VM_READ | PROCESS_QUERY_INFORMATION, FALSE, pid)`.
2. Enumerate regions: `NtQueryVirtualMemory(MemoryBasicInformation)` in a loop. For each committed RW region, `ReadProcessMemory` and search for:
   - API keys or bearer tokens (ASCII strings starting with `ey` or containing `Bearer`)
   - Cleartext passwords or certificates (PEM headers `-----BEGIN`)
   - URLs with embedded credentials (https://user:pass@...)
3. If the read was blocked, record `hold`.
4. If readable but no secrets found, record `hold` (data-at-rest protection or no cleartext secrets).
5. If cleartext secrets were found, record `miss` and describe what was found (type only, not the value).
6. Delete any dump files.
