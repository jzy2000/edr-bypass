# R-06

Test whether offline registry edits are detected.

1. Boot from a Windows PE USB/ISO (or attach the target VM disk to another VM).
2. Mount the SYSTEM and SOFTWARE hives from the offline disk: `reg load HKLM\OFFLINE C:\offline\Windows\System32\config\SYSTEM`.
3. Modify the product's service key: change ImagePath, Start type, or add a new value.
4. Modify the product's software key: change policy values.
5. Unmount: `reg unload HKLM\OFFLINE`.
6. Boot the target normally.
7. If the product detects the offline changes (integrity check, hash mismatch, cloud reconciliation), record `hold`.
8. If the changes persist and the product operates with the modified values, record `miss`.
9. Restore from snapshot.
