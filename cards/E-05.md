# E-05

Test the PE parser's robustness against malformed structures.

Build test PEs with these malformations:
1. **Export table**: RVA pointing outside the image, circular export forwarding, zero-length name.
2. **COM descriptor**: CLR header with invalid MetaData RVA, oversized blob.
3. **Certificate directory**: Authenticode blob truncated mid-ASN.1, certificate table size > file size.
4. **TLS directory**: TLS callback array RVA in an uninitialized section, callback count > 1000.
5. **Section table**: overlapping sections, section with VirtualSize=0, SizeOfRawData > VirtualSize.
6. **Optional header**: SizeOfImage < sum of sections, invalid AddressOfEntryPoint.

For each, attempt to execute or trigger a scan. Check:
- Does the product crash or BSOD? → `miss` (availability finding)
- Does the product misparse (loads a malformed PE as clean)? → `miss`
- Does the product reject and stay up? → `hold`
Delete all test PEs.
