# T-04

Test local database key protection.

1. Locate the product's local database: `dir /s /b "%data_dir%\*.db" "%data_dir%\*.sqlite"`.
2. Attempt to open with sqlite3. If encrypted, the key is needed.
3. Search for the key:
   a. In the agent binary: `strings <agent_exe> | findstr key`.
   b. In the agent's process memory (H-08).
   c. In registry: `reg query "HKLM\SOFTWARE\<product>" /s | findstr /i key`.
4. If the key is found and the database opens, search for sensitive data (policies, tokens, hostnames).
5. If the key is DPAPI-protected or TPM-bound, record `hold`.
6. If the key is in plaintext, record `miss`.
