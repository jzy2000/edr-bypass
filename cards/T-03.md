# T-03

Test whether token material is properly cleaned up.

1. Trigger an authentication event (agent check-in, policy fetch).
2. Immediately dump agent memory (H-08 procedure).
3. Search the dump for the token that was just used.
4. Search product log files for token material: `findstr /s /i "bearer token key secret" "%data_dir%\*.log"`.
5. If a crash dump exists, search it for tokens.
6. If tokens persist after use, record `miss`. If they are wiped, record `hold`.
7. Delete dumps.
