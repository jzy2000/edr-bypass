# G-05

Test file variant handling.

1. **Sparse file**: `fsutil file createnew sparse.dat 1073741824` then `fsutil sparse setflag sparse.dat` and `fsutil sparse setrange sparse.dat 0 1073741824`. The file is 1 GB logically but uses no disk space.
2. **Compressed file**: `compact /c /s:C:\TEMP\testdir`. Write a payload into the compressed directory.
3. **Reparse point**: create a mount point or junction: `mklink /J C:\TEMP\reparse C:\Windows\System32`.
4. For each, trigger the product's scanner and check for:
   a. Crashes (size overflow when allocating based on logical size)
   b. Bypass (scanner skips these file types)
   c. Correct handling
5. Record `hold` or `miss` per variant. Delete test files.
