# A-02

Gate: verify upstream guards.

For every `miss`:
1. Trace the input path from delivery to the vulnerable code.
2. Identify every size check, type check, format validation, and access control along the path.
3. If the PoC relied on a harness or tool that skipped one of these checks, the miss is a harness artifact.
4. Change such verdicts to `inconclusive` with a note about the skipped guard.
