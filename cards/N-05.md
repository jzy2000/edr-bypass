# N-05

Test whether last-gasp events can be forged.

1. From N-04, capture a real last-gasp or alert event (or infer the format from the agent binary strings).
2. Forge an alert: "Agent under attack, all threads suspended" — sent from a non-agent process.
3. Submit to the cloud endpoint.
4. If the cloud generates a real alert from the forged event, record `miss` — an attacker can create false alerts.
5. If the cloud rejects the forged event, record `hold`.
6. Also test the inverse: send "I am fine" after actually killing the agent. If the cloud believes it, record `miss`.
