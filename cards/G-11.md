# G-11

Compare 32-bit and 64-bit parser implementations.

1. If the product ships both 32-bit and 64-bit binaries (e.g., a WoW64 DLL and a native DLL):
2. Disassemble the same parsing function in both.
3. Compare:
   a. Integer sizes (are size fields 32-bit in both, or 64-bit in the native version?)
   b. Bounds checks (same thresholds?)
   c. Buffer allocation sizes
4. If the 32-bit version has weaker checks (e.g., 32-bit size that wraps), record `miss`.
5. If they are equivalent, record `hold`.
