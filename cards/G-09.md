# G-09

Test whether decoy processes can abuse trust heuristics.

1. Create a service with a name matching common security products: `sc create "WinDefend" binPath= "C:\TEMP\decoy.exe" start= demand`.
2. Start the service. Check if the product treats it differently (exclusion, reduced monitoring).
3. Create a window with a class name matching the product's UI.
4. If the product gives the decoy special treatment, record `miss`.
5. If not, record `hold`.
6. `sc delete WinDefend`.
