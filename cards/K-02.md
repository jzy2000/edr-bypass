# K-02

Repeat K-01 with HVCI enabled.

1. Enable HVCI if not already on: `bcdedit /set hypervisorlaunchtype auto` + Device Guard policy. Reboot.
2. Attempt to load the same vulnerable driver from K-01: `sc create TestVulnDrv type= kernel binPath= ...`.
3. `sc start TestVulnDrv`.
4. Expected: HVCI blocks unsigned or blocklisted drivers at the OS level.
5. Record whether the block came from HVCI (Error 577, or driver signing policy) or from the product.
6. If HVCI blocks it, the product's protection is redundant for this case but still valuable when HVCI is off.
7. If neither blocks it, record `miss`.
8. Cleanup: `sc stop TestVulnDrv & sc delete TestVulnDrv`.
