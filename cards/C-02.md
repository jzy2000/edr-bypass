# C-02

Test whether a boot-order race can occupy the filter port.

1. Create a service in an early load group: `sc create PortRacer binPath= "C:\\TEMP\\racer.exe" start= auto depend= "" group= "NetworkProvider"`.
2. The racer.exe attempts `FilterConnectCommunicationPort` in a loop on startup.
3. Reboot.
4. If the racer connects before the real agent, the real agent may fail to communicate with the driver.
5. Check `sc query <agent_service>`. If the agent is not running or is in an error state, record `miss`.
6. If the driver rejects the early connection or the agent recovers, record `hold`.
7. `sc delete PortRacer`. Revert from snapshot.
