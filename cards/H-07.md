# H-07

Test whether pre-existing handles in exempt processes can be stolen.

1. Run as SYSTEM (T2). Enumerate all handles: `NtQuerySystemInformation(SystemHandleInformation)`.
2. Filter for handles owned by `csrss.exe`, `services.exe`, `lsass.exe`, or `smss.exe` where the object type is Process.
3. For each process handle, check if the target PID matches the agent PID.
4. `DuplicateHandle(hExemptProcess, handleValue, GetCurrentProcess(), &dup, 0, FALSE, DUPLICATE_SAME_ACCESS)`.
5. Inspect `GrantedAccess` on the duplicated handle. If it contains PROCESS_VM_WRITE, PROCESS_TERMINATE, or PROCESS_CREATE_THREAD, record `miss`.
6. If no usable handles exist or all are already stripped, record `hold`.
7. Close all duplicated handles.

Note: ObRegisterCallbacks fires on the original open, not on duplication. Handles opened before the callback was registered may have full rights.
