# L-05

Test whether an early-boot service can race the product.

1. Check if the product uses ELAM: `bcdedit /enum {bootmgr}` and look for the product's early-launch binary.
2. Create a rogue service in the Boot load order group: `sc create RogueEarly type= kernel start= boot binPath= C:\TEMP\rogue.sys group= "Boot Bus Extender"`. Use a minimal signed test driver (or a renamed legitimate driver as a placeholder).
3. In the test driver's DriverEntry (or a user-mode service's main), attempt to connect to the product's filter communication port before the real agent starts.
4. Reboot.
5. If the product's ELAM driver blocks the rogue service or the product starts first regardless, record `hold`.
6. If the rogue service runs first and can interfere, record `miss`.
7. `sc delete RogueEarly`. Restore from snapshot.
