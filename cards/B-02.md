# B-02

Test maintenance token strength.

1. Extract the maintenance token mechanism from the agent binary (strings, decompilation).
2. If HMAC-based: is the key hardcoded or derived from machine identity?
3. If time-based (TOTP): extract the secret and generate tokens.
4. If challenge-response: capture and replay.
5. Search agent memory (H-08) for the token or key material.
6. If the token can be reproduced without cloud access, record `miss`.
7. If server-side validation is required and the key is not in the binary, record `hold`.
