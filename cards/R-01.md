# R-01

Test whether the product's CmRegisterCallbackEx blocks registry writes to its own keys.

1. From Session 1 admin (not WinRM, not SYSTEM), back up the target key: `reg export "HKLM\SOFTWARE\<product_key>" C:\TEMP\reg_backup.reg /y`.
2. Attempt to set a value: `reg add "HKLM\SOFTWARE\<product_key>" /v TestValue /t REG_SZ /d "probe" /f`. Record the result.
3. Attempt to delete: `reg delete "HKLM\SOFTWARE\<product_key>" /v TestValue /f`. Record the result.
4. Attempt on the service key: `reg add "HKLM\SYSTEM\CurrentControlSet\Services\<product_service>\Parameters" /v TestValue /t REG_DWORD /d 1 /f`.
5. If all writes returned ACCESS_DENIED and the product log shows a tamper/block event, record `hold`. If any write succeeded, record `miss`.
6. Restore: `reg import C:\TEMP\reg_backup.reg`. Delete the backup file.

Note: if the callback is not registered until the agent has connected to the cloud and received policy, test both before and after the first check-in (see R-02).
