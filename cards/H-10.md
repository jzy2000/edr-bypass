# H-10

Test whether CPU/memory starvation disables the agent.

1. Open the agent: `OpenProcess(PROCESS_SET_INFORMATION, FALSE, agentPid)`. If denied, record `hold`.
2. Set idle priority: `SetPriorityClass(hAgent, IDLE_PRIORITY_CLASS)`.
3. Starve working set: `SetProcessWorkingSetSizeEx(hAgent, (SIZE_T)-1, (SIZE_T)-1, 0)`.
4. Simultaneously, generate high CPU load to prevent the idle-priority agent from scheduling.
5. Run the S-03 baseline (write a test file). If the product still detects it within 30 seconds, record `hold`.
6. If detection stops or is delayed >60 seconds, record `miss`.
7. Restore: `SetPriorityClass(hAgent, NORMAL_PRIORITY_CLASS)`. Restart the service if needed.
