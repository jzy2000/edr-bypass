# F-11

Test whether the product protects Volume Shadow Copies.

1. List existing shadows: `vssadmin list shadows`.
2. Attempt deletion: `vssadmin delete shadows /all /quiet`.
3. Also try WMI: `wmic shadowcopy delete`.
4. Also try resizing VSS storage to 0: `vssadmin resize shadowstorage /for=C: /on=C: /maxsize=1MB`.
5. Read the product log. If deletion is blocked or alerted, record `hold`.
6. If all shadows are silently deleted, record `miss`.

Warning: this test is destructive. Shadow copies cannot be restored. Use in a lab VM with snapshot restore only.
