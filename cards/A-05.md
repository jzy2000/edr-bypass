# A-05

Gate: privilege verification.

For every `miss` demonstrated from WinRM or SYSTEM:
1. Note that WinRM runs as SYSTEM, which is often exempt from anti-tamper.
2. Re-run the same test from a Session 1 admin (RDP, runas, or scheduled task with /ru username /rp password /rl HIGHEST).
3. If it still succeeds from admin, the finding is valid at T1.
4. If it only works from SYSTEM, update the privilege to T2 and note the requirement.
