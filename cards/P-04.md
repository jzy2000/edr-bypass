# P-04

Test whether the product detects process hollowing.

1. `CreateProcessW("C:\\Windows\\System32\\svchost.exe", ..., CREATE_SUSPENDED)`.
2. Read the PEB to find the image base: `NtQueryInformationProcess(ProcessBasicInformation)` → `PebBaseAddress` → read `ImageBaseAddress`.
3. `NtUnmapViewOfSection(hProcess, imageBase)` — remove the original image.
4. `VirtualAllocEx(hProcess, imageBase, ...)` — allocate at the same base.
5. `WriteProcessMemory` — write a minimal PE (infinite loop or `ExitProcess(0)`).
6. `SetThreadContext` — point RIP/EIP at the new entry point.
7. `NtResumeThread` — the process-create callback already fired for svchost.
8. Read the product log. If the product detected the unmap, the foreign write, or the mismatched image, record `hold`. If the hollowed process runs, record `miss`.
9. Terminate the process.
