# X-05

Document firmware/bootkit coverage. This is usually a documentation question, not a lab PoC.

1. Review the product's documentation for firmware, UEFI, or bootkit detection claims.
2. Check if the product registers an ELAM driver (L-05).
3. Check if the product monitors Secure Boot state.
4. Check if the product monitors firmware updates or UEFI variables.
5. Record findings. This card is informational — a lack of firmware coverage is not a `miss` unless the product claims it.
