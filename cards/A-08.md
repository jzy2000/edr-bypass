# A-08

Gate: coverage of other callers and locations.

For every `miss`:
1. Are there other callers of the same function? If so, were they tested?
2. Are there other file paths where the same bug could be triggered? If so, were they tested?
3. If only one path was tested, the scope of the finding is understated. Test the others or note the limitation.
