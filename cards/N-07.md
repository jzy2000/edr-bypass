# N-07

Test whether crafted cloud policies can disable the agent.

Warning: this test requires a MITM proxy (N-03 prerequisite). Only perform in an isolated lab.

1. Capture a real policy delivery from the cloud.
2. Modify the policy:
   a. Set TTL to 0 or negative.
   b. Set rule list to empty.
   c. Set a sensor disable flag.
   d. Set anti-tamper mode to off.
3. Replay the modified policy through the MITM proxy.
4. If the agent accepts the policy and disables a sensor, record `miss`.
5. If the agent validates the policy (rejects, re-fetches from cloud, or alerts), record `hold`.
6. Restore from snapshot.
