# C-06

Test whether the driver uses process name as a trust signal.

1. Copy `notepad.exe` to `C:\TEMP\<agent_name>.exe`.
2. Run it.
3. From the impersonator, attempt to connect to the filter port.
4. If accepted (the driver only checks the process name), record `miss`.
5. Also try: create a window with the same class name and title as the product's UI. Some products check for a window to determine if the UI is running.
6. If the driver validates by more than name (hash, certificate, PID lookup), record `hold`.
7. Terminate the impersonator.
