# O-02

Test script host detection coverage.

1. Create a VBS payload: `CreateObject("WScript.Shell").Run "calc.exe"`.
2. Execute via each host:
   a. `wscript test.vbs`
   b. `cscript test.vbs`
   c. `mshta "vbscript:Execute(""CreateObject(""""WScript.Shell"""").Run """"calc"""":close"")"` 
   d. PowerShell: `Start-Process calc.exe`
   e. PowerShell constrained: `$ExecutionContext.SessionState.LanguageMode = 'ConstrainedLanguage'; ...`
3. Check the product log for each execution.
4. If all are detected, record `hold`. If any evade, record `miss` and name the host.
