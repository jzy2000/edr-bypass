# F-14

Test path-based trust and Mark of the Web.

1. Download or create a known-detected file. Confirm it is blocked in a normal location.
2. **Trusted path**: copy it to `C:\Windows\`, `C:\Program Files\`, or other OS-trusted directories. If the product skips scanning in these paths, record `miss`.
3. **MotW strip**: create a file with MotW (download from browser). Strip it: `Remove-Item -Path file.exe -Stream Zone.Identifier` or copy it to a non-NTFS volume and back.
4. Execute the stripped file. If the product no longer detects it, record `miss`.
5. If the product detects regardless of path and MotW, record `hold`.
6. Delete all test files.
