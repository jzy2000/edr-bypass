# X-03

Test autorun persistence detection.

1. Add Run key: `reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v EDR_TEST /d "C:\TEMP\marker.bat" /f`.
2. Add RunOnce: `reg add "HKCU\...\RunOnce" /v EDR_TEST /d "..." /f`.
3. Add to startup folder: `copy C:\TEMP\marker.bat "%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\"`.
4. Also add HKLM variants (requires admin).
5. Check the product log for each addition.
6. Reboot. Check if the marker executes.
7. If all are detected, record `hold`. If any evade, record `miss`.
8. Remove all entries.
